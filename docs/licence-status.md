# Licence status

Decision: open. No licence has been chosen and none has been added. The choice belongs to the project owner and must not be made on her behalf.

What an absent licence means. A public repository without a licence file does not grant general permission to copy, modify, use or redistribute its code. By default the author keeps all rights. Under the hosting platform's terms other people may view the repository and may fork it on the platform, but nothing more is granted.

Consequences for contributors and reviewers. Reviewers may read and run the code to assess it. Reuse in other projects should wait for a licence decision. Third party material was not added, and the preserved historical artifacts are the project's own earlier work packages.

Before choosing, the owner may wish to consider who else contributed to the preserved packages, any institutional policy that applies to student work, and whether documents and code should have different licences. This note is not legal advice.
