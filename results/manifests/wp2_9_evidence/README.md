# WP2.9 evidence pack (historical, labelled)

Logs and hashes from the WP2.9 work, produced in an isolated AI assistant sandbox before the code was moved into this repository. Paths inside the logs refer to that sandbox and are shown as `<workdir>`. The code now lives in `models/point_queue/wp2_9`, which has the same files except the directory prefix. `EXECUTION_RECORD.md` separates what was run in the sandbox from what was only written. Nothing here is a confirmatory run. These logs have not been reproduced by a human; the tests can be re run with `python tools/run_tests.py`.
