# Historical SUMO prototype results (exploratory, Phase 1)

These files were produced by the earlier SUMO prototype run (160 runs, SUMO 1.28.0) and are kept for traceability.
They are labelled historical: they were not generated by the repository scripts at the commit that added them, and
the raw 160 run archive (about 3.4 MB) is not committed. They are not a confirmatory experiment. The network is
synthetic and not calibrated to Dubai.

* `sumo_results.csv`: per scenario and policy aggregates.
* `sumo_results_paired.csv`: paired differences by seed.
* `aggregate_output.txt`: console output of `aggregate.py`.
